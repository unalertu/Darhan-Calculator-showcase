# Darhan Calculator

Darhan Calculator is an engineering platform for seismic hanger and brace design. It brings calculation workflows, company catalogs, user roles, and technical PDF reports into one guided experience.

- Guided seismic calculations
- Catalog-backed component selection
- Role-based project workflows
- Technical PDF reporting

[Open the live application](https://darhan-gilt.vercel.app/)

## Source availability

This repository is a product showcase. The calculation engine, catalog data, and application source code are private.
